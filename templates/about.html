Forensic Document Analysis Using Artificial Intelligence

AI Based Signature Verification for Forensic Document Analysis

This project is developed to verify handwritten signatures using Artificial Intelligence and image processing techniques.

The system compares a reference signature with a submitted signature and generates a similarity score to assist in identifying whether the signature is genuine or forged.

System Objectives

  • Detect genuine and forged signatures
  • Analyse signature patterns using image processing
  • Generate a similarity score for comparison
  • Reduce manual signature verification effort
  • Support forensic document analysis

Technologies Used

PythonFlaskOpenCVTensorFlowKeras HTMLCSSBootstrapJavaScriptMySQL

Key Features

  • Secure user registration and login
  • Reference and verification signature upload
  • AI-based signature comparison
  • Genuine or forged classification
  • Similarity percentage calculation
  • Verification history with date and time
